Star on GitHub
  1. v0.8.0 Latest Oct 31, 2026

    A canvas that draws itself

    • NewFlow and Wrap views next to Line. Line view now routes edges as rounded right-angle lines.
    • NewLive builds. When your agent saves a workflow, agent cursors draw each new card and edge in place.
    • NewScenes: Plain, Abyss Mesh, Seafoam, and Sorbet, each with its own card colours. Choose a scene and motion level in the appearance panel.
    • NewClick a step to open its details as a card on the canvas. Press Esc to close it.
    • NewA two-colour comet runs along traced edges to show each hand-off. It replaces the traveling bead.
    • ImprovedThe app controls float as islands. The title opens into one card with the workflow's purpose and the workflow list, and the dock fits in one row.
    • ImprovedEdges are thin lines with square ports, filled arrowheads, and plain-text labels.
    • ImprovedCards share one standard size and no longer have inner dividers.
    • ImprovedThe first-run screens draw a small map and type out the agent prompt. Agents map the repository overview first, then each workflow.
    • ImprovedEach view keeps its own dragged cards. Reset layout clears only the current view.
    • ImprovedLarge canvases stay fast, and the canvas fits phone screens.
    • RemovedThe full-details side panel, the card expand caret, card size options, and manual edge bending.
    • FixedThe diagram no longer flashes while you drag cards.
    • FixedWorkflow files saved with a UTF-8 byte order mark now load.
  2. v0.7.1 Sep 7, 2026

    A quieter navigator

    • ImprovedThe workflow navigator collapses to a thin rail, with a caret on the canvas to open it again.
    • ImprovedThe empty first-run screen no longer shows a Recheck files button.
  3. v0.7.0 Sep 7, 2026

    Repository maps and layouts that stay put

    • NewInteractive repository maps. The navigator shows your repo as a file tree, and Overview lives in the repository folder card.
    • NewCanvas layouts persist in the repository, so cards you arrange stay where you put them.
    • NewA traveling bead runs along success, async, and conditional edges, so the direction of flow reads at a glance.
    • ImprovedLogic cards are cyan and the happy path is ice blue.
    • FixedEditor links open correctly under WSL.
  4. v0.6.0 Aug 24, 2026

    Image export

    • NewExport the whole canvas as a PNG for docs and reviews.
    • ImprovedSharper card borders and cleaner right-angle edge routing.
    • RemovedSelf-graded confidence and status fields left the workflow contract. A map shows evidence, not a score.
    • RemovedThe bundled example workflow and its assets.
  5. v0.5.1 Aug 15, 2026

    One canvas, one story

    • ImprovedEdges route around cards instead of through them.
    • ImprovedWork cards share one standard size, so maps line up.
    • RemovedThe separate Code map view. The canvas tells the story, and each card holds its code details.
  6. v0.5.0 Aug 12, 2026

    Smoother navigation

    • ImprovedPolished canvas navigation, with clearer guidance on what to do next.
    • ImprovedA simpler workflow contract for agents to write.
  7. v0.4.0 Aug 8, 2026

    Edges that follow your cards

    • NewA collapsible workflow navigator.
    • NewDrag a card and its edges switch to the sides that face each other, outcomes included.
    • ImprovedStep cards are tinted by category, with a new category palette.
    • FixedThe copy button copies every install command shown.
  8. v0.3.0 Aug 2, 2026

    A horizontal canvas

    • NewThe workflow canvas is redesigned to read left to right.
    • ImprovedA refined visual foundation, without the duplicate dots on arrival points.
  9. v0.2.0 Aug 1, 2026

    CodeHQ is now HQFlow

    • ChangedNew name, same tool. The CLI is hqflow.
  10. v0.1 Aug 1, 2026

    First public release

    • NewOpen source under MIT and published to npm.
    • NewA live canvas that redraws as your agent writes workflow files, with offline exports.
    • Newhqflow init scaffolds the .codehq/ contract your agent reads.
