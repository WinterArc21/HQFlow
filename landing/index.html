03 / THE MAP

The map lives in your repo.

No database and no account. It is plain JSON next to the code it explains, so it moves through the same review as the code.

  • .codehq/One JSON file per workflow, next to the code.
  • git commitShip the map in the same pull request as the change.
  • any agentCursor today, Claude Code tomorrow. They all read the same files.
  • missing fileWhen a step points at a file that is gone, HQFlow flags the step.

04 / TRUST

Local-first, no LLM inside

No model, no API keys, no accounts, no telemetry. HQFlow uses the agent you already have, and your code never leaves your machine.

Evidence attached

Every step carries its real files, symbols, inputs, outputs, edge cases, and tests. Check any claim in one click.
